Script che esegue simulazioni di piani di ammortamenti francesi o italiani
Permette di scegliere se effettuare il calcolo in anni o rate 
Converte automaticamente il tasso annuo nel tasso equivalente sulla base della frequenza dei pagamenti
Restituisce un grafico che mostra l'incidenza degli interessi sul debito totale e l'andamento della curva degli interessi nel tempo
